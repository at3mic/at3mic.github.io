## Projects

> [!ABSTRACT] [Akari Linux](https://github.com/akari-linux)
> My idea with Akari Linux is making a minimal, bloat-free Linux distribution based on Ubuntu, with options to tailor it
> for gaming, studio, etc.
>
> The problem I see with existing gaming distributions such as [CachyOS](https://cachyos.org/) and [Ultramarine Linux](https://ultramarine-linux.org) is: CachyOS is a rolling distribution based on Arch Linux.
>
> By all means, Arch Linux is not a *bad* distribution. The problem is that my apps can suddenly stop working due to a core
> system package being updated.
>
> As for Ultramarine Linux, I do not like it's vision on using Flatpak primarily for installing applications. I also do not
> like RHEL-family distributions in general.
